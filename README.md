# OpenVK Mobile

Кастомная тема для [OpenVK](https://github.com/openvk/openvk). Проект создавался как эксперимент по полной переработке интерфейса OpenVK **на уровне вёрстки**.

>  Тема находится в разработке. Некоторые страницы и элементы интерфейса могут быть ещё не полностью переработаны или требовать доработки.


## За что? 🥀

Основная идея проекта — взять существующую систему themepack OpenVK и использовать её для максимально глубокой переработки интерфейса:

* изменять HTML/Latte-шаблоны через тему
* полностью заменять внешний вид страниц
* добавлять собственный JavaScript там, где это необходимо
* адаптировать интерфейс под мобильные устройства
* постепенно приводить разные разделы OpenVK к единому дизайну


## Почему новая тема?

Потому что адаптивная мобильная версия которая реализована сейчас - пиздец полный. Лучше уж полноценную мобильную тему иметь

## Как это делалось

Основой проекта стали оригинальные Latte-шаблоны OpenVK.

Вместо того чтобы создавать отдельное приложение или переписывать backend, я постепенно заменял существующую разметку страниц собственной.

Ну и кншн же вайбкодинг) 

## Адаптивность

Сделана полностью новая вёрстка адаптированная под:

* смартфоны
* планшеты
  
На мобильных устройствах часть элементов интерфейса превращается в более компактные компоненты, включая выдвижное меню.


## Компоненты интерфейса

В процессе разработки постепенно формировалась собственная система компонентов.

Например:

* кнопки
* поля ввода
* формы
* карточки пользователей
* посты
* комментарии
* вложения
* меню
* модальные окна
* вкладки
* навигация
* аудиоплеер
* элементы профиля
* элементы групп


## Аудиозаписи

Отдельно перерабатывался интерфейс аудиозаписей.

Целью было сохранить существующую функциональность OpenVK.

JavaScript и необходимые части оригинального OpenVK можно использовать непосредственно внутри темы, когда это позволяет сохранить существующую функциональность без изменений OpenVK.


## Состояние проекта

Проект развивается постепенно. Некоторые разделы уже имеют полностью переработанный интерфейс, другие находятся в процессе переноса.

Поэтому возможны:

* недоработанные страницы
* визуальные несоответствия
* ошибки в отдельных Latte-шаблонах
* компоненты, которые ещё используют старую разметку
* различия между desktop и mobile
* необходимость адаптации темы под конкретную версию OpenVK
